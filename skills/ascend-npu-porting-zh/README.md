# 给 GLM 的昇腾 NPU 适配使用指南

这是可独立复制的通用中文 skill，用于把用户指定的 PyTorch 模型推理或训练适配到昇腾 NPU。无需 Codex、MCP 或此前聊天记录。GLM 所在宿主需要文件读写、Shell，以及目标机访问能力；只有文本 API 时只能生成方案和补丁，不能声称实测成功。

## GLM 从这里开始

1. 完整读取同目录的 [SKILL.md](SKILL.md)，再按其中的表格读取当前阶段需要的参考。不要一开始读取所有案例。
2. 从用户输入及已有 `ledger.md` 确认当前首要目标、源码目录、目标机、资产位置、权限与步数预算；只询问无法从现有资料确定的必要信息。
3. 续接任务时先查已有进程和最新结果，再执行下一条必要动作；已经通过且条件未变的检查不重做。
4. 真正使用目标解释器运行实际入口。把每次失败定位到第一处因果错误，由你修改、重跑，并保存实际退出状态和模型证据。

如果整个技能包初次复制到新宿主，可以执行一次 `python3 scripts/self_check.py`（工作目录为本 skill 目录）。它只验证离线工具行为，不能证明 NPU 或模型可用；不要每次恢复对话都重跑。

## 先选当前目标

| 用户目标 | 先做什么 | 本阶段成功意味着什么 |
|---|---|---|
| 尽快打通训练 | [快速训练模式](references/fast-training.md)：已有资产优先，完整原模型、真实数据、一次有效更新 | 有限 loss/梯度、参数实际变化；另核对目标 rank、保存及真实退出码 |
| 验证推理 | 对应完整权重与真实输入的实际推理入口 | 原始浮点输出及任务输出通过检查，运行退出 0 |
| 验证恢复 | 从已有保存状态启动新进程 | 模型、optimizer、scheduler、计数、RNG、消费进度恢复后再次更新 |
| 性能或效果 | 在功能正确的基础上测用户指定指标 | 只报告实测吞吐、显存或任务指标，不从单步训练推断收敛 |

没有固定卡数、batch、模型组件或分片方案。用户指定 8 卡时直接面向该拓扑；批量大小可在可行性范围内调整并报告差异。不能静默冻结主干、换成 LoRA、裁剪模型或使用随机输入。

## 可直接交给 GLM 的启动提示

将下面方括号中的输入替换为本次实际信息；已知信息不必让用户重复填写。

```text
你是本次 NPU 适配的执行者。先读取 [本目录绝对路径]/README.md，
再读取同目录 SKILL.md，并按当前目标选择参考文件。

项目：[仓库地址、revision、工作目录]
目标：[目标机访问方式、已有解释器/环境、已授权节点和卡数]
资产：[本机/目标机路径；若有 OBS，提供已授权前缀和现有访问方式]
首要目标：尽快打通完整原模型的真实训练，先完成 1 次有效 optimizer 更新。
后续目标：[保存、恢复、推理中本次真正要求的项目；没有则写无]
资产 hash：[快速可行性默认不额外校验；若用户要求则明确范围]
执行范围：[本轮可修改目录、输出目录及资源限制]
独立性：[普通协作，或 GLM 独立编写和调试模型代码]

先复用已有资产及有效检查记录，只补齐训练必需项。不要等待仅供推理
使用的发布 checkpoint，也不要先完成全量审计再训练。
保持模型结构、真实任务和可训练模块契约；运行参数差异如实记录。
由你完成代码修改和实际测试，记录 loss、梯度、真实参数变化、每 rank
信息和 launcher 退出状态。先排除证据采集错误，不能把失败断言改名为通过。
每个尝试使用唯一目录；断线先检查仍在运行的任务，避免重复启动。
```

用户后续纠正优先于模板和旧计划，例如“资产先扫描 OBS”“不要校验 hash”。立即更新台账当前区；不需要修改冻结 skill，也不需要再次请求已经给出的授权。

## 续接时只传必要信息

```text
继续本次 NPU 适配。skill 路径：[路径]；ledger：[路径]；源码：[路径]。
先读台账当前区和最新运行结果，接续活跃任务。
最新用户变更：[本次新增要求；没有则写无]。
保留已有代码和产物，不重做已经通过且条件未变的检查。
```

台账当前区保持简短：最新目标与 hash 策略、最强已证实结论、活跃 attempt/PID/日志、第一处失败、下一条动作。旧结论和过时计划移到历史区。宿主不能运行中追加消息时，应保存状态后续接，不能把新会话当新实验从零开始。

## 工具与参考

- [工具说明](references/tools.md)：环境探测、风险扫描、SSH、持久退出记录；工具按需要调用。
- [真实训练与恢复验收](references/validation.md)：框架更新时点、参数名、梯度和权重差异证据。
- [GLM 交接与独立性](references/glm-handoff.md)：控制端允许的协调与应记录的实现介入。
- [官方参考链接](references/official-links.md)：按目标已安装版本查询，离线时读取已安装源码。
- [FastWAM 经验附录](references/fastwam-lessons.md)：只在相关问题出现时阅读，里面的参数和版本不是新模型默认值。

使用本包不会自动创建云作业、下载资产、上传仓库或发起训练。具体操作依据用户本次授权执行；模型支持情况以对应真实运行证据为准。
