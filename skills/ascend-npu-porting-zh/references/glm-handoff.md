# GLM 执行与交接

## 宿主能力

GLM 是模型，文件读写、Git、Shell、SSH 和长任务能力由宿主提供。官方 [GLM skills 仓库](https://github.com/zai-org/GLM-skills) 使用目录式 skill；本包同时支持显式读取 `SKILL.md`，不要求特定宿主自动发现机制。

第一次使用确认：能完整读取本目录、定位实际仓库、编辑文件、执行明确工作目录下的命令、取得日志和退出码，并保存台账。只有文本 API 而没有工具时，不能声称已经执行适配；生成可交接材料即可。

目标可达则直接工作。目标不可达但能检查源码时，生成补丁、环境契约和命令包（哈希按交付要求），状态标为“已准备”；由有权限的一方执行后再回收证据。不要把远端未执行的命令写成已通过。

## 少读、少重做，保留上下文

- 开始时读入口文件及本轮用到的参考；通过一次检查后存档。读工具输出被截断时补齐对应范围，不重复拼接整个目录。
- 使用 `rg --files` 定位，再读取指定文件或 JSON 字段。不要递归扫描下载、权重、原始事件日志；一行日志可能包含整段历史输出。
- 长任务启动前落盘：目标、attempt、进程身份、输出目录和判定方法。阶段完成或失败立即更新 ledger。
- 接续时先对照最新事件和目标状态；台账滞后时补充记录，不盲信最后一段总结。复用活跃会话/进程，结束前先核实再重试。
- 服务商暂时不可达时保留运行状态；恢复后先检查模型任务是否仍在执行。额度拒绝时保存错误，不连续付费探测，不擅自切换模型或充值。

台账顶部只维护一个当前区：最新用户目标/资产策略、最强结论、活跃 attempt 与进程/日志、首个因果错误、下一条必要动作。失效的“下一步”移到历史区，不能在新指令下保留两个相互冲突的当前计划。只读相关源码片段和日志字段；不要每次接续重新调查项目、依赖和全部资产。

控制端需要传达新要求时优先使用宿主支持的续接能力。宿主不支持运行中追加消息时，先保存自身会话身份和当前状态，再续接原工作目录及台账；不自动停止模型任务或从零重做。模型任务是否需暂停由用户变更的实际影响决定，任何停止先核实所有权。

## 独立性

普通适配任务可以在授权范围复用已有代码和诊断。若用户专门验证“GLM 仅靠 skill 能否独立适配”，则：冻结本包 manifest；给 GLM 干净项目 revision、目标访问资料和真实资产契约；记录实际模型/宿主；模型代码由 GLM 编写和执行。审查者可检查原始证据，但提供实现答案或现成补丁需记为介入。

分别记录资源/执行协调（资产位置、用户优先级、启动或续接宿主）与实现介入（诊断解法、补丁、其他模型编写的测试代码）。会话被续接不自动失去代码独立性，也不能称作完全无人干预的单次会话。原始资产和符合契约的缓存复用规则见 [快速训练与资产准备](fast-training.md)；独立实验并不默认禁止所有派生缓存。

实验使用的 skill 副本保持冻结。后续总结写入新版本，不把新指南或其他模型的复盘答案注入仍在进行的独立实验。技能文档检查通过、GLM 阅读理解通过和新模型实测通过是三个不同结论。

不要把首轮辅助开发的成功写成独立完成。技能可移交、格式检查通过和 GLM 理解说明，也不等于在新模型上的独立验证通过。

## 任意新模型的提示模板

下面文本在用户真正启动新模型任务时使用；本包本身不启动训练。将“目标项目”替换成当前模型名，提供源码 revision、目标及已授权资源。FastWAM 只是该模板的一个使用实例；不要从旧项目猜新模型地址、分支、权重格式或模态布局。

初次使用优先采用 [README 的带输入启动模板](../README.md)。以下是精简交接版本；训练优先及资产 hash 策略由本次用户目标补充。

```text
你是本次目标项目 NPU 适配的 GLM 执行者。
先完整读取随包 ascend-npu-porting-zh/SKILL.md，再按当前任务选择参考文件。

输入由本次用户提供：目标项目仓库及固定 revision、目标节点访问方式、
可用 NPU/节点数、权重与真实数据位置、验证目标和更新步数预算。
缺失信息先从可访问的仓库和节点只读核实；确实无法推断时仅询问缺失项。

从实际启动入口重新建立源码、依赖、模型和数据契约；
不要复制历史项目专属张量形状、缓存键名、模块补丁或其通过结论。
按用户指定的拓扑和真实模型任务验证。通过的前置检查不重复执行。
本轮独立性要求如已约定，则不读取目标项目已有的 NPU 适配补丁。

使用唯一 run/attempt 目录；长任务由目标端持久监督器记录真实退出码。
保存具体命令、环境、每 rank 训练指标、参数变化、产物和未测项。
断线后先检查已有任务，避免重复启动。适配源代码和门禁执行由你完成。
最终交付适配补丁、中文 NPU_PORTING.md 及真实证据，报告最强已证实结论。
```
