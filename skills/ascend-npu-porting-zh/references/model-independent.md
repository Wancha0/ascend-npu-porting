# 陌生模型适配方法

不知道模型名字不影响开始源码分析；不能据模型名字猜测实现或支持状态。本流程适用于能检查源码和执行入口的 PyTorch 项目。非 PyTorch、只有闭源二进制或特殊部署格式的项目，先确认可用的昇腾后端/转换路径，再确定本 skill 能处理的边界。

## 从实际任务建立执行图

先找当前 revision 的 README、launcher、配置加载器和模型构造入口，再追踪：

```text
用户任务 → launcher/解释器 → 框架/模型构造 → checkpoint 加载
                               ↓
真实数据 → processor/dataloader → forward → loss → backward → optimizer
                               ↓                         ↓
                          任务输出验收                 checkpoint/恢复
```

推理任务只需相关前向路径；训练任务还要分析反向、优化器及状态恢复。不要为每个模型预先创建同一套入口文件，更不要要求它具有 DiT、VAE 或 ControlNet。

输出一张当前项目的能力表：

| 能力或依赖 | 当前实现/位置 | 目标版本是否支持 | 候选处理 | 验证证据 |
|---|---|---|---|---|
| 设备/AMP | 从源码填写 | 支持/不支持/未知 | 集中设备路由或保持原实现 | 实际 dtype/device |
| 核心算子 | 从实际 forward/backward 填写 | 同上 | 原生、等价 fallback 或新算子 | 真实形状及数值/梯度 |
| 分布式 | 框架与包装位置 | 同上 | 保持框架或有依据地调整 | rank 映射/同步/更新 |
| 权重/状态 | 格式、量化及恢复接口 | 同上 | 原样严格加载或明确转换 | keys/shapes/恢复更新 |

“未知”表示需查目标版本资料或做最小针对性测试，不表示必须替换。静态扫描只生成候选，不把所有 CUDA 字符串机械改成 NPU。

## 根据实际能力选择检查点

下面的类别可重叠，仅用于找到应该检查的接口；不是已支持模型名单。

| 项目实际包含的能力 | 需要保留和验证的语义 |
|---|---|
| 卷积、检测、分割 | 布局、卷积/归一化、插值、索引/NMS 等自定义算子；输出尺寸及任务后处理 |
| 自回归 Transformer | attention mask、位置编码、KV cache、prefill/decode、可变序列、loss shift；训练与生成分开验收 |
| MoE / 稀疏计算 | 路由、排序/分组算子、专家分布、动态未使用参数、all-to-all；普通稠密模型通过不能外推 |
| 扩散/视频模型 | scheduler/timestep、latent 与条件布局、分辨率/帧数、attention；缓存是否与当前分支一致 |
| 多模态/语音/机器人 | 各模态 processor、padding/mask、时间和动作对齐、缺失模态语义及独立损失；不能通用化某个案例的空音频张量 |
| 检索/图网络/自定义扩展 | embedding、scatter/gather、稀疏操作和动态 shape；检查反向支持与精度 |

每个候选修复按“失败证据 → 原语义 → 目标实现 → 验证”记录。设备路由、版本核实、日志和验收方法通常可复用；模型专属 mask、cache key、权重转换、并行包装及冻结策略必须重新决定。

## 不预设内存与训练方案

用户要求全参数训练时，不得自动改成 LoRA、冻结主干或仅训练一个条件网络；允许的参数子集由任务决定。根据实际可训练参数、dtype、optimizer、激活和主存预算选择策略。卡数、序列长度、精度和 offload 均来自当前契约，没有全模型通用默认值。

保留可用的原生实现；不支持时优先范围最小、能验证数值的替代。涉及量化、编译模式、算子融合或不同分布式算法时，明确其语义/性能变化和验证成本。无法保持用户要求时报告具体阻碍，而不是缩小任务后宣称完成。

## 对新模型得出自己的结论

需要真实输入、实际模型路径、按目标拓扑运行、对应任务输出/参数变化与实测退出状态。沿用[模型验收](validation.md)的证据层级，算法效果另行评测。

遇到未列出的框架或算子，依据[官方资料索引](official-links.md)先查项目自己的固定 revision 和依赖版本，再查昇腾支持；必要时寻找该项目/框架维护者的官方 NPU 实现。未找到官方支持不等于绝对不可适配，也不能以相似案例声称支持。
