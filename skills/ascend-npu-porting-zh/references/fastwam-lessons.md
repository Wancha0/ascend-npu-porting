# FastWAM 适配经验：按问题读取

这是 2026-09-08 已观察到的一次训练记录摘要，用于解释通用规则。不是新模型默认配置，也不是新版 skill 已完成独立复测的声明。

源码来自[官方 FastWAM](https://github.com/yuantianyuan01/FastWAM/tree/7faa71108368fbb3b6885649f112af607427a2d4)，固定 revision `7faa71108368fbb3b6885649f112af607427a2d4`。任务为官方 LIBERO uncond，完整视频/动作专家及任务指定的可训练模块；冻结 VAE。环境是单节点 8×910B1 64GiB、PyTorch/torch_npu 2.6.0、CANN 8.2.RC1、Accelerate 1.12.0、DeepSpeed 0.18.5。环境差异和具体数值不能外推到其他版本。

## 可复用的决策

| 观察到的问题 | 应提炼的通用规则 |
|---|---|
| 开始从外网下载，用户提醒后才发现 OBS 已有训练资产 | 先定位授权的既有资产，只下载必需缺失项；用户要求 no-hash 时不要用全量校验阻塞训练 |
| 项目包未安装，文本预处理入口报 `ModuleNotFoundError` | 用实际解释器/工作目录检查 import，隔离安装项目且保护平台 torch 组合 |
| RoPE 乘法探针通过，真实前向却在 complex128 `cat` 失败 | 局部测试覆盖真实构造、搬运和消费路径，不能从一个算子的支持推断另一个 |
| NPU RoPE 使用 float32/complex64 后，BF16 差异断言仍失败 | 区分算子错误、参考转换和容差公式错误；保留失败，按 dtype/幅度解释数值，不任意放宽阈值 |
| 采样参数名使用共享模块别名，实际 `named_parameters()` 已去重 | 从实际参数遍历选择有效名字并检查覆盖数量 |
| backward 后 `.grad` 缺失、原采样参数差值为零 | 核实框架更新时点与梯度缓冲；在真正更新前快照，必要时用 hook 和保存权重后验比较 |
| 对比原始 FP32 权重与训练 BF16 权重出现 dtype 差异 | 初始化参考经过与实际加载一致的转换后再测变化 |

## 已证明的范围

记录中的 `train-002` 使用 BF16、AdamW、ZeRO1/HCCL、每卡 batch=2（官方配置为 16），名义全局 batch=16。模型可训练参数为 6,020,710,599，真实 LIBERO 数据来自四套任务。

一次训练得到全局 loss `2.0079574584960938`、梯度范数 `10.152502059936523`；8 rank 的 loss/梯度范数有限且未报告跳步。保存权重与按实际 BF16 转换后的初始化参考比较，在视频专家多层抽样权重中确认非零变化，最大绝对差 `0.0001220703125`。launcher 实测退出码为 0，模型/优化器等 checkpoint 产物已写出。该后验只证明抽检权重变化，不声称全部参数均更新。

这证明该配置的一次真实训练更新和保存执行可行。本文不对长期稳定性、收敛、任务效果、完整推理或严格恢复作通过声明；它们需要各自证据。RoPE 局部探针中存在失败断言，不能被完整训练成功抹掉或改写成全部局部测试通过。
